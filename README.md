# Task Management System

REST API для управления задачами. Приложение позволяет создавать, просматривать, обновлять и удалять задачи, управлять их статусами и искать задачи по заданным критериям.

## Технологический стек

- **Java 21**
- **Spring Boot**
- Spring Web MVC
- Spring Data JPA, Hibernate
- PostgreSQL
- Maven
- Docker

## Возможности

- Создание, получение, обновление и удаление задач.
- Управление статусами задач: `CREATED`, `IN_PROGRESS`, `DONE`.
- Назначение исполнителей и указание создателей задач.
- Установка приоритетов и сроков выполнения.
- Фиксация времени завершения задачи.
- Поиск задач с фильтрацией по заданным параметрам.
- Пагинация результатов поиска.
- Проверка бизнес-правил при изменении статусов задач.

## API

| Метод | Эндпоинт | Описание |
|---|---|---|
| `GET` | `/tasks` | Получение списка задач |
| `GET` | `/tasks/{id}` | Получение задачи по ID |
| `POST` | `/tasks` | Создание задачи |
| `PUT` | `/tasks/{id}` | Обновление задачи |
| `DELETE` | `/tasks/{id}` | Удаление задачи |
| `POST` | `/tasks/{id}/start` | Начало выполнения задачи |
| `POST` | `/tasks/{id}/complete` | Завершение задачи |
| `GET` | `/tasks/filter` | Поиск задач по фильтрам |

## Запуск проекта

### Требования

- Java 21
- Docker Desktop
- Git

### 1. Клонирование репозитория

```bash
git clone https://github.com/NikitArias/task-management_system.git
cd task-management_system
```

### 2. Настройка базы данных

Создайте файл `.env` в корне проекта и укажите пароль пользователя PostgreSQL:

```dotenv
DB_PASSWORD=root
```

При необходимости замените значение на собственный пароль.

Запустите PostgreSQL командой:

```bash
docker compose up -d
```

### 3. Запуск приложения

Откройте проект в IntelliJ IDEA и настройте переменные окружения для подключения к базе данных:

- `DB_URL` — `jdbc:postgresql://localhost:5433/postgres`
- `DB_USERNAME` — `postgres`
- `DB_PASSWORD` — пароль, указанный в `.env`

Запустите приложение через главный класс Spring Boot.

После запуска API будет доступно по адресу `http://localhost:8080`.
