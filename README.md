# Task Management System

REST API для управления задачами. Приложение позволяет создавать, просматривать, обновлять и удалять задачи, управлять их статусами и искать задачи по заданным критериям.

## Технологический стек

- **Java 21**
- **Spring Boot**
- Spring Web MVC
- Spring Data JPA, Hibernate
- PostgreSQL
- Maven
- Docker

## Возможности

- Создание, получение, обновление и удаление задач.
- Управление статусами `CREATED`, `IN_PROGRESS`, `DONE`.
- Управление приоритетами задач.
- Назначение исполнителя и указание создателя задачи.
- Установка дедлайна и фиксация времени завершения.
- Фильтрация по создателю, исполнителю, статусу и приоритету.
- Пагинация результатов поиска.
- Проверка бизнес-правил при запуске и завершении задач.

## Структура проекта

- `TaskController` — обработка HTTP-запросов.
- `TaskService` — бизнес-логика приложения.
- `TaskRepository` — доступ к данным через Spring Data JPA.
- `TaskEntity` — JPA-сущность задачи.
- `Task` — модель задачи, используемая API.
- `TaskMapper` — преобразование между моделью API и JPA-сущностью.

## API

| Метод | Эндпоинт | Назначение |
|---|---|---|
| `GET` | `/tasks` | Получить все задачи |
| `GET` | `/tasks/{id}` | Получить задачу по ID |
| `POST` | `/tasks` | Создать задачу |
| `PUT` | `/tasks/{id}` | Обновить задачу |
| `DELETE` | `/tasks/{id}` | Удалить задачу |
| `POST` | `/tasks/{id}/start` | Начать выполнение задачи |
| `POST` | `/tasks/{id}/complete` | Завершить задачу |
| `GET` | `/tasks/filter` | Найти задачи по фильтрам |

### Пример фильтрации

`GET /tasks/filter?assignedUserId=1&status=IN_PROGRESS&pageSize=10&pageNumber=0`

Параметры фильтрации можно комбинировать. `pageNumber` начинается с `0`.

## Запуск

Требуются Java 21, Docker и Docker Compose.

1. Склонируйте репозиторий.
2. Запустите PostgreSQL через Docker Compose.
3. Настройте переменные окружения для подключения к БД.
4. Запустите приложение через Maven Wrapper.
